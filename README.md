# Weekly board

A small static page showing one first-grade class's homework for the current
Monday-Friday week. Built by a parent, for the other parents in the class.

It is not official, not affiliated with the school, and it is assembled
automatically, so it can be wrong or out of date. Confirm anything that matters
with your teacher.

The page is read-only. It stores nothing about you and sends nothing anywhere;
the only thing it keeps is which tab you last looked at, in your own browser.
